# ADR-003 — Schéma complet de la v1 dès la migration 1

Statut : proposé · 2026-11-26

## Contexte

L'ancienne version a enchaîné 8 migrations avant sa publication, dont 3 sur les créneaux et les groupes.

## Décision

Le schéma couvre F-01 à F-14 dès la migration 1 (créneaux ponctuels, plusieurs groupes, états de séance, brouillon, alertes traitées), même si les écrans arrivent plus tard. Avant la publication, la migration 1 peut être corrigée ; après, jamais.

## Options écartées

Tables ajoutées jalon par jalon (chemin de l'ancienne version).

## Conséquences

Le jalon 1 contient des tables encore inutilisées. Décision du porteur du 2026-11-26.
